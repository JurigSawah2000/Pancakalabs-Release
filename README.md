## 🎯 Detail & Deskripsi Aplikasi

### 1. 🎓 CBT-GoExa (Computer-Based Test Platform)
> **Solusi Ujian Berbasis Komputer & Handphone Mutakhir untuk Sekolah dan Madrasah**

CBT-GoExa dirancang menggunakan bahasa pemrograman **Go (Golang)** berkinerja tinggi serta database terisolasi **PostgreSQL** lokal yang teroptimasi. Aplikasi ini mampu menangani ribuan siswa secara bersamaan dalam satu komputer server sekolah tanpa memerlukan internet (100% offline LAN) maupun mode online.

* **Fitur Unggulan:**
  * ⚡ **High Concurrency Go Backend:** Ringan, hemat RAM, dan anti-lag saat ribuan siswa submit jawaban bersamaan.
  * 🤖 **AI Question Generator:** Otomasi pembuatan soal pilihan ganda, esai, dan AKM dengan integrasi ChatGPT & Gemini AI.
  * 🏫 **Integrasi Dapodik Kemendikbud:** Impor data siswa, guru, rombel, dan mata pelajaran sekali klik dari database Dapodik lokal.
  * 🔒 **Anti-Cheat Lockdown:** Deteksi tab switching, kunci fullscreen, dan proteksi integritas lembar ujian.
  * 📱 **Multi-Platform Klien:** Siswa dapat mengerjakan via browser laptop, PC, Android, maupun iOS.
* **Persyaratan Sistem Minimum:**
  * OS: Windows 10 / 11 (64-bit)
  * RAM: Minimal 4 GB (disarankan 8 GB+ untuk >500 siswa)
  * Disk: 1 GB free SSD
  * Network: Switch LAN / Access Point Wi-Fi sekolah

---

### 2. 🌐 KONEKA-LINK (Akses Jaringan Instan)
> **Hubungkan Aplikasi Lokal Sekolah ke Internet Secara Instan, Aman, dan Gratis**

KONEKA-LINK adalah utilitas networking yang memungkinkan aplikasi web lokal di komputer Anda (seperti **Dapodik**, **E-Rapor**, atau Web Server lokal) diakses dari mana saja melalui internet menggunakan teknologi terowongan aman (*secure tunnel*).

* **Fitur Unggulan:**
  * 🔄 **Auto-Detect:** Otomatis mendeteksi port Dapodik dan E-Rapor yang sedang berjalan.
  * 🆓 **100% Gratis:** Bebas biaya langganan dan tanpa batasan waktu pemakaian.
  * 🛠️ **Auto-Fix E-Rapor:** Perbaikan otomatis aset gambar dan stylesheet agar tampil sempurna di perangkat luar.
  * 🛡️ **Enkripsi End-to-End:** Akses aman HTTPS tanpa perlu IP Publik Statis atau port forwarding router.

---

### 3. 📊 TPKS (Teman Pintar Kelola Sekolah)
> **Sistem Manajemen Administrasi, Keuangan, dan Akademik Sekolah Terpadu**

Aplikasi desktop terintegrasi untuk membantu pihak sekolah dalam mengelola absensi, rekapitulasi nilai, SPP/keuangan, hingga arsip data induk kesiswaan dengan sinkronisasi cloud real-time.

### 4. 🗳️ TPS-DIGITAL (Sistem E-Voting Modern)

Sistem pemilihan umum digital untuk tingkat organisasi, sekolah (Pemilihan Ketua OSIS), perguruan tinggi, maupun pemilu komunitas. Menggunakan sistem **Single Vote Token QR** dan audit log kriptografis yang transparan serta anti-kecurangan.

## 🚀 Panduan Instalasi

1. **Unduh Berkas Installer:**
   Pilih aplikasi yang diinginkan dari [Tabel Katalog](#-katalog-aplikasi--unduhan) di atas.
2. **Jalankan Installer:**
   Klik ganda pada berkas installer (`.exe` atau `.msi`).
   * *Catatan:* Aplikasi tidak mewajibkan *Run as Administrator* karena installer telah mengonfigurasi permission folder pengguna secara otomatis.
3. **Selesaikan Wizard:**
   Ikuti langkah-langkah di layar hingga selesai. Shortcut aplikasi akan otomatis dibuat di Desktop dan Start Menu Windows.
4. **Buka Aplikasi:**
   Jalankan aplikasi melalui shortcut desktop. Untuk aplikasi server seperti CBT-GoExa, buka browser dan akses alamat yang tertera pada jendela utama.

## 🛡️ Verifikasi Integritas (Checksum SHA-256)

Untuk memastikan keaslian berkas installer dan mencegah kerusakan berkas saat pengunduhan, Anda dapat memverifikasi nilai SHA-256 melalui PowerShell:

```powershell
Get-FileHash -Path ".\Nama-Installer-Setup.exe" -Algorithm SHA256
```

Bandingkan nilai hash yang dihasilkan dengan hash rilis resmi di halaman [GitHub Releases](../../releases).
